Moodle Release Pack

A verified question-bank handoff for Moodle: merges previously exported Moodle XML banks into one import file plus a per-question receipt — category, stable id, source line and SHA-256 — so a reviewer can spot-check before importing.

Purchase order and invoice path

  1. Quote: email support@rhemahq.com with your institution name, billing contact and quantity; we return a formal quote.
  2. Vendor forms: W-9 / vendor-registration / security questionnaires — request by email; we complete and return them.
  3. Payment: card checkout via Polar (link provided on the quote). Polar is merchant of record and calculates applicable tax.
  4. Invoice: a tax invoice with your company/institution name and VAT or tax ID is self-served from the Polar customer portal linked in the receipt email — suitable for finance reimbursement.
  5. Delivery: license key by email immediately after payment; tool download and README included.

What it does not do

It does not author questions, assign grades, or decide import approval. Grading, content and pedagogical decisions remain the institution's. Duplicate question ids within a category are rejected rather than silently merged.

Evaluation before purchase

A free evaluation download and a live browser demo are available at rhemahq.com. Run a representative exported bank through it before raising a PO.
