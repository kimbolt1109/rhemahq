# Sync Sanctuary — rhemahq.com
Static marketing site plus live in-browser demos for three source-verified handoff tools.
## Run
npm test
npx serve .
## Deploy
GitHub Pages from repo root; custom domain rhemahq.com via CNAME file and Spaceship DNS A/CNAME records.
## Status
Demos run client-side on synthetic or user-selected files; nothing is uploaded. Capabilities verified on synthetic fixtures; live customer validation in progress. Paid licenses open at launch.

## Pages
- `index.html` — landing, demos, downloads, Polar checkout links (UTM-tagged).
- `refund.html`, `privacy.html`, `terms.html` — trust/policy pages (Polar is merchant of record).
- `thanks.html` — post-checkout landing; reads `?checkout_id={CHECKOUT_ID}` (set as Polar checkout-link success URL).
- `procurement.html` — print-friendly institutional one-pager for the Moodle pack (quote/PO/invoice path).
- `services.html` — fixed-scope done-for-you engagements.
- `guides/` — five source-cited how-to pages + hub; `sitemap.xml`, `robots.txt` at root.
Static pages are generated by `scripts/build_site_pages.py` (idempotent; edit the script, not the emitted HTML).

## Instrumentation
`src/track.js` queues first-party events (`page_view`, `demo_start`, `demo_build`, `demo_download`, `eval_download`, `checkout_click`, `support_click`) from `data-track` attributes. It makes no network calls unless a sink exists: add a Plausible snippet (`window.plausible`) or GA4 (`window.dataLayer`) and events forward automatically. Checkout links carry `utm_source=rhemahq&utm_medium=site&utm_campaign=<product>`; Polar preserves UTMs and reports checkout conversion + net revenue in its analytics.

## 3D layer
src/scene.js renders a Three.js (r170 via CDN importmap) centerpiece: a verified seal, orbiting source-shards, provenance threads, drifting particles and bloom; scroll drives the camera, pointer adds parallax, hover raycasts a live receipt tooltip.
Fallbacks: prefers-reduced-motion renders one static frame; small/coarse devices skip bloom and reduce shard/particle counts; if WebGL is unavailable the canvas is removed and a CSS gradient stands in; the canvas fades out below the hero so content reads on the void.
