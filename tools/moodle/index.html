Moodle Release Pack

Merges approved Moodle XML question banks into a single import file plus a row-by-row receipt — category, stable id, source line and SHA-256 — so a reviewer can spot-check before importing. Handles multichoice, truefalse, shortanswer, numerical, essay and cloze, and preserves embedded files. Runs entirely on this page.
