A repeatable editorial handoff

Sample Editor

Introduction

An editorial handoff is easier to review when the production files share the same accepted text. This demonstration follows one synthetic manuscript through print, web, and structured XML.

Methods

We prepared a short accepted manuscript with section headings and a metadata record. The same source was used to generate an HTML galley, a two-column PDF, and JATS Publishing XML. We checked the article title and compared the section order across the three outputs.

Results

The print galley presents a two-column layout. The HTML version preserves headings for reading on the web. The XML records the journal and article metadata in structured elements and separates the front matter from the body.

Conclusion

A repeatable conversion step gives a production editor a consistent starting point for proofreading and registering each galley in OJS.
