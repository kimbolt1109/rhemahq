Reconcile Fulfyld Billing Detail Reports without losing the source row

Fulfyld publishes an itemized Billing Detail Report (BDR) per invoice. It is the right input for a tie-out — but only if every billed row keeps its original address, so a disputed line can be re-opened in the exact file it came from.

Getting the export

Download the CSV attached to an Invoiced invoice or export the detailed Excel report from the Billing section of the Fulfyld dashboard. Check the header names in your own file before mapping the fee fields.

Fields that matter for a tie-out

FieldUse in reconciliation
DateMonth bucket (normalize Excel serials to ISO dates first)
Order numberJoin key back to your order system
SKULine-level identity
Service type / fee labelRollup label — keep the provider's exact wording
QuantitySum only where supplied; blank stays blank
Unit costBlank stays blank; do not infer
TotalSigned amount — credits stay negative

The workflow

  1. Collect the BDR CSVs for the period, one per invoice. Keep the original filenames.
  2. Normalize dates. Spreadsheet exports often carry Excel serial numbers; convert to YYYY-MM-DD before bucketing by month, or your rollup grows a "46114.3" month.
  3. Roll up by provider × currency × month × exact fee label. Count rows, sum quantities only where present, sum signed totals.
  4. Keep a source-reference sheet: retain the original file name and SHA-256, together with the worksheet row or CSV record, label and total. CSV records include the header and can span more than one text line if a field contains a quoted line break.
  5. Review exceptions — labels that changed wording mid-period, currencies mixed in one invoice, credits without a matching charge. The workbook surfaces them; a human decides.

What this is not

A consolidation and evidence workbook is not an error detector and not a ledger posting. It does not decide that a charge is wrong; it makes every charge re-openable. Published "3–15% billing leakage" figures in this market are vendor-reported — WareAudit's own site notes no independent study exists — so treat any error-rate claim, including ours if we ever made one, as marketing until measured on your own bills.

Do it with the tool

Open the original export in Fulfillment Ledger. If the headers differ from its standard columns, use the column-matching dialog. Check which source columns represent the date, service type and signed total. Set a provider or currency for the sheet only after checking the invoice. The workbook records the selected file's original checksum and source positions.
