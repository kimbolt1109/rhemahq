OJS Galley Studio

Renders a Word manuscript and its metadata into a two-column PDF, standalone HTML and JATS Publishing 1.2 XML, then hands them to OJS's add-galley action. The editor approves layout, names and rights.

  • Verified on OJS 3.5.0.4
  • JATS 1.2 DTD clean
  • PDF · HTML · JATS

Fulfillment Ledger

Consolidates 3PL invoice exports into one reconciliation workbook: every fee label rolled up by provider, month and currency, and every billed row kept with its original file, worksheet, line and file hash.

  • Edge + native Excel
  • CSV · XLSX in, XLSX out
  • Per-row source address

Moodle Release Pack

Merges approved Moodle XML question banks into a single import file plus a row-by-row receipt — category, stable id, source line and checksum — so a reviewer can spot-check before importing.

  • Moodle 4.5.16 / 5.2.5 / 5.3.1
  • 6 types incl. Cloze

The proof travels with the file.

Local by default

Files are read on your device. Only a small license check ever leaves it — never your invoices, manuscripts or question banks.

Address + hash per row

Every billed row or question keeps its original filename, worksheet or line, and a SHA-256 of the source, so a reviewer can re-open exactly what was read.

Equivalence, not invention

The tools serialize and compare what you supplied. They never guess an answer, assign a ledger account, or make a teaching or tax decision.
